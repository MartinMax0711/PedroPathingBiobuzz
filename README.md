# Pedro Pathing Visualizer · BIOBUZZ Edition

A Pedro Pathing path planner for the FTC 2026–2027 BIOBUZZ season, based on [Pedro-Pathing/Visualizer](https://github.com/Pedro-Pathing/Visualizer) (Apache-2.0). It has a field drawn from the official manual, G304 start-pose checks, one-click red/blue alliance switching, collision warnings, a 30 s AUTO timer, and Java/Kotlin code export.

Live site: https://martinmax0711.github.io/PedroPathingBiobuzz/

Run locally (Node.js 22.18+):

```bash
npm install
npm run dev
```

Not affiliated with FIRST. Always check field dimensions against the official game manual.
